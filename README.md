# Helios

Helios is a small Python web framework. It includes:

- [HTTP request and response handling](packages/framework/src/helios/http/)
- [Routing with optionally typed parameters](packages/framework/src/helios/routing/)
- [Application, dependency container, and request contexts](packages/framework/src/helios/app/)
- [WSGI adapter and test client](packages/framework/src/helios/wsgi/)
- [SQLite-backed models and queries](packages/framework/src/helios/database/)
- [View rendering](packages/view/src/helios/view/)
- [Form validation](packages/framework/src/helios/form/)
- [File-backed sessions](packages/framework/src/helios/session/)
- [Authentication](packages/framework/src/helios/auth/)
- [Flash messages](packages/framework/src/helios/flash.py)
- [Rate limiting](packages/framework/src/helios/limit/)
- [Environment configuration](packages/framework/src/helios/config.py)

It is small enough to read and understand in an afternoon.
